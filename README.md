# CAT MANAGER UPDATE REPOSITORY

This repository is dedicated exclusively to CAT Manager protected update distribution.

It does not contain:
- Website Source Code.
- Backend Source Code.
- Desktop Application Source Code.
- Adobe Extension Source Code.
- Original Development Files.

Updates are distributed through verified GitHub Releases.

Mỗi phiên bản Release chứa các Patch được ký số và xác minh trước khi cài đặt.
